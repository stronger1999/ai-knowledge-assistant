# AI Knowledge Assistant

An AI-powered document assistant that enables users to upload documents, ask questions, and receive context-aware answers using Retrieval-Augmented Generation (RAG).

---

## Features

- User Authentication
- AI Chat Interface
- PDF Upload & Processing
- Retrieval-Augmented Generation (RAG)
- Semantic Search
- Chat History
- Source Citations
- Multi-user Support
- REST API

---

## Architecture

```text
User
 ↓
Next.js Frontend
 ↓
FastAPI Backend
 ↓
PostgreSQL

Backend
 ↓
Vector Database (Qdrant)

Backend
 ↓
LLM API
```
